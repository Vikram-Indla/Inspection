Each prompt targets one complete first return, one independent review, and—only if required—one consolidated correction. Unresolved P0/P1 after that correction becomes an explicit blocker rather than another prompt loop.

CD-005 contains the enhanced pre-verified runtime-truth contract. CD-018 and CD-019 may remain blocked where their dedicated acceptance addenda are not approved. Design generation does not authorize application implementation.
