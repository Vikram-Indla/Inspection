# P08 — Evidence, Findings, Violations, and Actions

Use the master constitution plus the evidence/media prompt. Cover SCR-IPAD-640/650 and SB08/SB15. Inspect Workspace.tsx, FactoryVerification, ImageAnnotator, storage/outbox behavior, violation configuration, penalty context, and action forms.

Design an evidence-led flow for photo, video, document, note, scan, annotation, compression, metadata, item/finding linkage, location/time, queued upload, retry, replacement, archive, deletion reason, and chain of custody. Then design finding creation, severity, clause linkage, configured violation trigger, single-penalty semantics, corrective action owner/due date, and submission-blocking status.

Required states: camera/media permission denied, format/size failure, corrupt file, compression, annotation, queued offline, upload progress, synced, failed, retrying, replaced, archived, deletion pending, rule unavailable, missing evidence, action incomplete, and unauthorized lifecycle action. Never imply a hash or malware scan exists unless shown by runtime data.

Return iPad and virtual companion designs, accessible media controls, Arabic/RTL metadata layout, evidence-count/provenance patterns, and acceptance evidence requirements.
