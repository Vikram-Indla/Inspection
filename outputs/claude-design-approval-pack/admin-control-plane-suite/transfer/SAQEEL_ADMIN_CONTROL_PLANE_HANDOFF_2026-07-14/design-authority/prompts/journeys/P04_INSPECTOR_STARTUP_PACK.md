Use the master constitution. Cover SCR-IPAD-600/610 and SB06. Inspect `apps/web/src/app/field`, `components/field/FieldHome.tsx`, Startup.tsx, offline package handling, and map components.

Design a purpose-built 1024×1366 field experience, not a responsive desktop page. The assignment dashboard must prioritize today, returned work, urgency, visit state, route, and offline readiness. The startup pack must combine factory/visit identity, exact package version and hash, Factory 360 snapshot, prior findings, contacts, documents, map, appointment, execution eligibility, and readiness diagnostics.

Required states: package not downloaded, downloading, verified, corrupt, outdated, insufficient storage, low battery guidance, offline ready, weak/no GPS, network unavailable, wrong mode, returned assignment, expired assignment, and ready. Persistent status must show what is local, what is verified, and what blocks start.

Return portrait and landscape iPad designs, sunlight/light theme, dark theme, Arabic/RTL, touch/keyboard behavior, interruption recovery, and P05 handoff.
