Current-screen critique — 3 highest-cost decision failures (evidence: admin/page.tsx, read 2026-07-14)
1 · Failure is rendered as health. Six parallel reads share one fate: an errored count becomes 0, and a static "live database" success lozenge sits above it regardless. An admin can look at a page where regulations failed to load and read "0 regulations · live database". Cost: the one screen meant to answer "is tomorrow's configuration safe?" can assert safety while blind.
2 · Counts without lifecycle answer no admin question. "412 inspection items" carries no draft/published/locked identity, no version, no owner-role, no next action — and its caption is a raw internal ID ("SCR-ADM-010"). The 30-second decision (what can harm tomorrow's inspections?) is unanswerable from equal cards. Cost: every real decision requires opening each module anyway.
3 · The gateway hides six of its eight doors. Only regulations and audit are linked; packages, violations, workflows, risk, GIS and access exist as governed routes but are reachable only via the sidebar. The page also shows every count to every admin role identically, with no per-role scoping of what they may act on. Cost: the control plane reads as a report, not a place to act safely.
