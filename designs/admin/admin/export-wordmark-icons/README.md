# SAQEEL Wordmark & Favicon

- **saqeel-favicon.svg** — icon-only mark (shield + check), 32x32 viewBox, steel fill on transparent — use as-is for favicon.ico generation / <link rel="icon">.
- **saqeel-wordmark-dark-mode.svg** — full lockup ("SAQEEL | صقيل"), white text — use on dark backgrounds/dark mode pages.
- **saqeel-wordmark-light-mode.svg** — full lockup, dark text (#1d1f20) — use on light backgrounds/light mode pages.

For a page that supports both themes, swap between the two wordmark files via CSS (e.g. hide one with prefers-color-scheme or your theme attribute) rather than trying to recolor a single file at runtime.
