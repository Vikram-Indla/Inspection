Lifecycle contract

Transitions are server RPCs. The UI never computes a stage; it renders the stage it was given and offers only the transitions the server declared available for this user on this revision.

Draft → Submitted

Maker only. Requires at least one component. Locks the revision for review.

Submitted → Under review / Returned

Checker only, maker ≠ checker enforced server-side. Return requires a reason.

Approved → Published

Transactional across approved branches; assigns immutable version ids. Partial publication is not possible.

Any → Rejected

Terminal for the revision. Reason mandatory; record retained and auditable.
