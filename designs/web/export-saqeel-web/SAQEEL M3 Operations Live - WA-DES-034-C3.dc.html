Route/trail conflict (unresolved, flagged not decided here)

The system prompt asks for a route trail; SPC-CMD-005 (row status not_started, but binding once implemented) requires no route/navigation drawn in Phase 1. Default safe disposition used here: markers/operational-state only, no route line, no path animation, no ETA. This page does not implement the trail.

Freshness

No "stale" boolean or amber threshold is invented — only a plain last-observed timestamp plus an explicit freshness-policy-unconfigured note, since no staleness cadence is governed anywhere in engine_settings today.

Wallboard cadence

No auto-refresh interval is specified, implied, or shown as a countdown. If an implementation re-fetches periodically for operational reasons, that interval must not be surfaced to the viewer as a governed cadence.

Fixture disclosure

Inspector markers/timestamps shown are illustrative design fixtures, not real telemetry — no location/accuracy/consent/playback is designed as active per AUTHENTICATED_LIVE_OPERATIONS_MAP.md's "future telemetry-ready mode."
