Key structural gap

Figma models a report-type selector (نوع التقرير) at plan creation that branches the entire flow — Visit Report vs. Customs Exemption vs. Chemical Clearance vs. Safety. The current implementation flattens records into a single Visit Report accordion. Requirement: plan creation must expose report type, and the downstream record set + fields must switch on it.
