Current-state diagnosis (from source)

The foundation is sound — governed tokens, bilingual IBM Plex Sans Arabic, logical-property RTL, light/dark. The premium gap is composition: the report (reports/inspection/[id]/page.tsx) is 8 equally weighted chapters on a fixed 210mm sheet with 48px padding; every status is a filled lozenge; dates come from toISOString().slice() (UTC, not Asia/Riyadh); whole sections carry break-inside:avoid; the border token (#D6DDE2) is 1.37:1 against white — below the 3:1 non-text-contrast floor when it is the only control boundary.

Conflicts & assumptions raised before designing

1. Texture conflict — current authenticated rules prohibit decorative texture/gradient. Frames use one 1–2% measurement-tick / prism motif in brand chrome only, flagged as a V2 experiment needing explicit approval. 2. Hijri policy — frames show Gregorian with a labeled slot for dual-calendar; the Gregorian/Hijri policy needs stakeholder + legal approval, not a design assumption. 3. Human report number — a governed report reference (vs UUID slice) requires a data-model decision; frames show INS-9F2A41C7 as the interim governed form. 4. No production code was edited; V2 values live only in this exploration's --v2-* scope.

Recommendation — hybrid, weighted editorial

A1 for the Official Report + B2 for the Review Workspace. The report is a legal artifact: Editorial's numbered-chapter, rule-driven composition converts to A4 almost losslessly, achieves the largest box reduction (31→12), and reads as a governed state document rather than an app screen. Review is repetitive operational work: Command's issue-queue canvas, status rail and evidence panel cut reviewer traversal (queue → issue → evidence → decision in one eye-line) and its sticky decision bar is the strongest governed-action pattern. The two share every V2 primitive proposed here (28/32 metric, 3:1 control border, 3 surface levels, Riyadh date grammar, chip/status language), so the hybrid is one system, not two. If one direction must rule both, choose Editorial (A1+B1) — lower risk, still a 46% container reduction on review.
