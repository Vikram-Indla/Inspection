# Saqeel V2 — competitive benchmark
- **Primary premium benchmark — Palantir Foundry Workshop**: dense-but-readable operational apps, object/record context, governed actions, lineage, common operational picture. We benchmark qualities, never copy branding/layouts/components.
- **Direct domain competitor — SafetyCulture**: mobile-first inspections, offline continuity, evidence capture, corrective actions, reports/approvals. Saqeel must exceed it on governance, legal reporting, immutability, bilingual parity.
- **Enterprise functional references**: IBM Maximo Mobile, ServiceNow FSM — functional scope only, not visual density.
- **iPad benchmark — Apple iPadOS HIG**: adaptive layouts, orientations, Split View, touch/pointer/keyboard/Pencil, Dynamic Type, RTL, minimal modal interruption.
Acceptance is evidence-based (see acceptance criteria in COMPONENT-SPEC and the reference screens), not adjective-based.
