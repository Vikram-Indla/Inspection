5 · Arabic / RTL & Accessibility rules

  • RTL is native, not mirrored CSS hacks: all components use logical properties (inline-start/end); directional glyphs (breadcrumb ›, stepper →) flip via [dir=rtl] rules. Toggle above demonstrates live.
  • DEC-004 boundary: Arabic capability is designed; Arabic scope (which surfaces, MVP1 vs MVP2-016) is an open executive decision. No bilingual commitment here.
  • Contrast: body text ≥7:1, secondary ≥4.5:1, semantic-on-tint pairs ≥4.5:1. No colour-only status — every lozenge pairs glyph + label (MVP1-FND-011).
  • Focus: 2px offset ring (--ax-focus-ring) on every interactive element; visible on all demos.
  • Targets: ≥40px desktop, ≥48px iPad/field-critical.
  • No zoom-required reading: minimum body sizes enforced by the semantic scale; micro size reserved for uppercase labels only.
  • Reduced motion honored; live/pulse indicators degrade to static.
