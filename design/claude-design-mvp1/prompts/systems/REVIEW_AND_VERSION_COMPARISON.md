# System Prompt — Review and Version Comparison

Inspect review routes, DecisionPanel, report rendering, returned sections, version data, evidence changes, audit, and negative tests.

Design queue prioritization, immutable review, exact-section return, locked comments, correction context, and N versus N+1 comparison. The diff must handle fields, sections, evidence, findings, violations, action forms, metadata, added/removed/unchanged values, and missing/incompatible versions.

Use side-by-side and focused changed-section navigation with textual change labels, not color alone. Preserve read-only prior versions and maker/decision safeguards. Include degraded evidence, stale assignment, decision failure, and repeated return.

Acceptance IDs: SPC-REV-001 through SPC-REV-007.
