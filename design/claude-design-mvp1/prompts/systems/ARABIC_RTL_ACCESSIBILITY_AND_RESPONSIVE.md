# System Prompt — Arabic, RTL, Accessibility, and Responsive Design

Inspect i18n runtime, localization Admin, generated keys, Shell, tokens, ThemeScript, field tabs, current CSS logical properties, and Playwright persona tests.

For every golden journey, provide English/LTR and Arabic/RTL behavior. Mirror layout and navigation meaningfully while keeping identifiers, coordinates, dates, codes, and charts readable. Test long Arabic labels, mixed-direction content, tables, filters, map controls, timelines, diffs, evidence metadata, and validation.

Required viewports: 1440 desktop, constrained desktop/tablet, and 1024×1366 iPad portrait/landscape. Require WCAG AA, semantic headings/regions, keyboard order, visible focus, ≥48px field targets, 16px inputs, reduced motion, screen-reader labels, error summaries, and non-color-only status. Dark and light are equal themes; light must be suitable for sunlit field work.

Acceptance IDs: DSG-A11Y-001, DSG-IPAD-001, and the screen-state matrix.
