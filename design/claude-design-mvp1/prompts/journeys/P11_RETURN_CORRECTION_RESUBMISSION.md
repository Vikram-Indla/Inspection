# P11 — Return, Correction, and Resubmission

Use the master constitution plus the review/version prompt. Cover SCR-IPAD-670/SCR-WEB-320 and SB10/SB17. Inspect returned-scope enforcement, version creation, immutable comments, evidence changes, and comparison rendering.

Design the complete loop: reviewer returns exact sections → inspector sees reason/comments → only returned sections unlock → inspector corrects and adds evidence → resubmission creates N+1 → prior version remains locked → reviewer compares and decides.

Required states: one/multiple returned sections, locked-section edit attempt, offline correction, conflict, resubmission blocker, queued resubmission, new version created, missing comparison version, package-version incompatibility, field/evidence/action differences, no-change warning, and repeated return. Use side-by-side plus focused changed-section navigation; never rely on color alone.

Return paired iPad and desktop designs, Arabic/RTL diff behavior, audit/version annotations, and proof that selective locking remains understandable and enforceable.
