# Premium UI/UX Programme Context

## Objective

Create a complete, source-backed premium KSA Inspection Platform UI/UX revamp over the existing implemented MVP1/MVP2/MVP3 application. The work starts from factual system capture and governed product evidence, not a new visual concept.

## Success outcomes

1. Complete route/persona/state screenshot baseline.
2. Minimum 25 UI and 25 UX findings per distinct screen or logical mode.
3. Minimum 200 deduplicated platform improvements.
4. Requirement-to-screen-to-finding-to-design-to-code-to-test-to-evidence traceability.
5. Sponsor-locked shared design system proven through five existing-product golden screens.
6. Complete onboarding, Persona Academy, real-character video and four-hour demonstration specification.
7. Complete Minister/Leadership national command, map/list and governed conversational-AI specification.
8. Claude Design addenda using the locked shared system.
9. Controlled implementation only after design acceptance.
10. Internal audit evidence and a sponsor-readable completion position.

## Design direction

- Premium means calm Saudi institutional confidence, authentic industrial context, clear operational hierarchy, evidence truth and excellent Arabic/RTL—not decoration or novelty animation.
- Preserve the governed shared shell and functional behaviour while improving navigation, persona visibility, hierarchy, density, responsive behaviour and accessibility.
- Use real people, authentic industrial settings, correct PPE, bilingual production and governed media rights for learning content.
- Preserve map and provider truth: projected routes are not live GPS; unavailable AI/video/provider states must fail honestly.
- Treat the iPad as a true field application and Admin engines as control planes.
