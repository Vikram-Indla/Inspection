# IPAD_TOUCH_AND_ACCESSIBILITY
- Targets ≥44px (field density guarantees; --touch-target token); 8px min gap between adjacent targets.
- No hover-dependent affordances: row actions visible ⋯ buttons; tooltips have visible-label equivalents.
- Focus ring identical (external keyboards); VoiceOver: same ARIA contract as desktop; status announced via role=status pills.
- Reduced motion honoured; drag interactions (map) always have button equivalents (zoom/locate).
