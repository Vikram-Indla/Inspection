# IPAD_DESIGN_PRINCIPLES
iPad is a primary product target (field inspectors), not a compressed desktop.
1. Every control is a touch target: [data-density="field"] — controls 40/44/52px, rows 52px, body 15px.
2. One-hand flow: primary actions bottom-reachable (field taskbar), cards over wide tables for task lists.
3. Offline is the default assumption: SyncIndicator + offline Alert always present in field chrome.
4. Same identity as desktop: identical tokens, status vocabulary, evidence treatment (continuity pattern).
5. Nothing desktop-only: every canonical screen renders at 1024×768 and 768×1024.
