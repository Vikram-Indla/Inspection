# SAQEEL Inspection — design principles
1. **Quiet confidence** — authority through hierarchy, alignment and restraint; no decoration.
2. **Colour means something** — emerald = interaction; status colours = fixed semantics; nothing tinted for looks.
3. **Density with dignity** — compact operational surfaces, never cramped; whitespace is purposeful.
4. **Two languages, one system** — Arabic composed intentionally (own leading, zero tracking, LTR-embedded identifiers), never mirrored mechanically.
5. **Dark mode is designed, not derived** — layered charcoal, edge-based elevation.
6. **The map is workspace** — never tinted, never decorated; controls float, geography stays legible.
7. **Field-to-command continuity** — the same inspection object (ID, status, severity, evidence language) is recognisable on tablet, register, map, review and dashboard.
Structural lineage: Industry (grid discipline, compact controls, table architecture). Dark-mode lineage: Nocturne (surface layering, selection contrast) — no purple, no glow. Final identity: original to SAQEEL.
