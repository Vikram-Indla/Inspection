# ICONOGRAPHY_SPECIFICATION
- One family: **Lucide** (https://lucide.dev), stroke 1.5, round caps/joins.
- Sizes: 16px in controls, 17px nav, 13–15px inline/meta, 20px upload/empty plates, 28px empty states.
- Directional icons (chevrons, forward/back arrows, pagination) flip under RTL (data-directional / logical components). Status shapes, clocks, numbers never flip.
- Status is never icon-only: ExceptionMark = shape + colour + label.
- No emoji, no mixed families, no filled variants. Map markers use Lucide glyphs inside status-toned keyline circles.
