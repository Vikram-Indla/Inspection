Finding, violation and corrective-action card — 3px severity edge, requirement clause, evidence count. The edge is the only left-border accent in the system, reserved for severity.

```jsx
<FindingCard kind="violation" refCode="VIO-2026-0122" severity="critical"
  title="Blocked emergency exit — warehouse B" requirement="Civil Defense Code 4.2.1"
  due="28 Jul" evidenceCount={3} actions={<Button size="sm" variant="secondary">Add corrective action</Button>} />
```
