# STATUS_AND_SEVERITY
One vocabulary everywhere (signature: Operational Exception Rail).
- 10 status roles with fixed meanings (readme + tokens.status.json). Presentation: StatusBadge (dot+label soft chip) for lifecycle; ExceptionMark (shape+colour+label) for severity/exceptions: ▲ critical ◆ major ■ warning ○ pending ▨ onhold ● compliant ◎ completed.
- Severity: SeverityIndicator bars (3/2/1) on findings; 3px card edge; 4px RailCell in tables. These edges are the ONLY colour edges in the system.
- Same tones drive map markers, spine dots, chart emphasis, KPI value tinting.
- Rules: colour+label (or shape) always; base colours never at body text size; one severity language across web and iPad.
