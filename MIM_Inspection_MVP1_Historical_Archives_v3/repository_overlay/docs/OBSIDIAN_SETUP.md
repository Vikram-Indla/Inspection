# Obsidian Setup

The repository root is the Obsidian vault.

## Rules
- Never copy the product contract into another vault.
- Never store secrets in Obsidian notes.
- Use `HOME.md` as the human landing page.
- Treat links and graph view as navigation only; the source files remain authoritative.
- Commit approved documentation changes through Git.

## Recommended use
- Review gates and decisions.
- Navigate process, screen, data and session relationships.
- Record workshop notes as proposed decisions, not as silent contract changes.
- Convert approved decisions through change control.
