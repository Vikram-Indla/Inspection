# Memory Disaster Recovery

## If a chat is lost
Start from repository root and invoke `/inspection-session-start`.

## If a machine is lost
Clone the repository. The authoritative product contract and session ledger return. Auto memory may be lost and is not required.

## If an Obsidian vault is corrupted
Reopen the repository root as a new vault. Product files remain ordinary Markdown/CSV/YAML/JSON.

## If instructions conflict
Stop. Compare CLAUDE.md, rules, current slice and gate status. The product contract and approved change record prevail.

## If the ledger is incomplete
Do not resume implementation. Reconstruct from Git commits, test evidence and the last session files first.
