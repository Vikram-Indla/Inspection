# Procedure
- Verify 100% P0/P1 scenarios for the slice.
- Verify runtime, API/data, audit and visual evidence.
- Verify no unauthorized mock or open blocker.
- Rerun protected regression.
- Mark accepted only when all mandatory evidence exists.
