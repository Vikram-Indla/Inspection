# Procedure
1. Read root `AGENTS.md`.
2. Read current state, gate status, current slice, task router and open decisions.
3. Inspect Git branch, status and last five commits.
4. Read only the context named in the current slice.
5. State task ID, gate, IDs, dependencies, blockers, do-not-touch areas and evidence.
6. Do not implement until the user approves when required.
