# Fable Release-Back Template

Fable must use this structure at the end of the understanding gate and each design wave.

## Release type
`UNDERSTANDING_GATE` or `DESIGN_WAVE`

## Status
`READY_FOR_REVIEW`

## Scope completed
- Requirement IDs
- Journey IDs
- Storyboard IDs
- Screen IDs
- Acceptance IDs

## Functional understanding or output
- What was understood/designed
- User goals
- Actions and branches
- Validation and error states
- Permissions and role behavior

## Technical understanding or output
- Backend engines
- API/data dependencies
- Integrations
- Offline behavior
- Audit/versioning
- Performance/degradation behavior

## Acceptance understanding or coverage
For each criterion:
- input;
- actor;
- screen/state;
- visible result;
- system result;
- failure result;
- proof required;
- design frame reference.

## Traceability
`Requirement → Journey → Storyboard → Screen → State → Acceptance → Frame`

## Open questions
- Exact question
- Affected IDs
- Source conflict or missing value
- Whether design can proceed safely

## Coverage summary
- total in scope;
- completed;
- incomplete;
- blocked;
- confidence by domain.

## Declaration
`I have not self-approved this output and have not invented unresolved rules.`
