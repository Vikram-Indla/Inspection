# Planning Implementation Sequence

This is one programme executed in a loop, not a sequence of sponsor prompts. Kimi may split work internally or into parallel worktrees, but returns once with a consolidated branch.

1. Freeze latest `origin/setup/Inspection` SHA and register a Planning slice.
2. Read all source files and every existing Planning/Admin/Visit/Factory/API path.
3. Produce internal preservation, schema, route, RLS and test maps.
4. Add compatibility-safe canonical capabilities and Planning data structures.
5. Converge list/entry points while preserving every route.
6. Complete Single and Manual/Immediate.
7. Complete Bulk criteria, persisted draft, eligibility and assignment.
8. Complete optional packages and authoritative publish.
9. Complete return/cancel/expiry/duplicate/list/detail/export.
10. Complete Admin planning configuration and role workflow.
11. Reconcile dashboard/operations/field handoffs.
12. Run migrations locally/staging only as authorized.
13. Run typecheck/build/static/full tests.
14. Run Kimi browser certification at `http://127.0.0.1:3000`.
15. Fix every engineering-controlled failure and rerun affected/full regression.
16. Push one branch and return evidence; do not merge/deploy without sponsor acceptance.
