# Approval Sequence

The design work should now proceed in only three approvals.

## Approval 1 — Astryx Foundation

Review:

- colour and typography;
- layout density;
- desktop and iPad grids;
- Arabic/RTL direction;
- core and enterprise components.

Decision: approve the design language or request one consolidated correction.

## Approval 2 — Six Golden Screens

Review:

1. Admin Package & Form Designer
2. Single Visit Planning
3. Inspector Assigned Visits/Startup
4. Inspector Inspection Workspace
5. Level 2 Review/Comparison
6. Operations Center

Decision: approve the product experience and visual standard.

## Approval 3 — Complete Prototype

Review the wired physical-inspection journey and complete screen coverage.

Only after Approval 3 should Claude Code treat the Fable output as the visual implementation authority.

## What is intentionally not required

- another BRD;
- another architecture document;
- another user-journey rewrite;
- hundreds of pages of design commentary;
- implementation before the visual authority is approved.
