Flagged AR/EN contradictions and source anomalies (indexed as written, not resolved):
- SYS-BR-008: Permission matrix (4.1.4) has no column for Sector Manager for Task Management, though the RACI table and UC001 both name Sector Manager as a task-management actor.
- SYS-BR-011: Permission matrix grants Questionnaire Management to System Administrator (Technical); F004 and UC004 both assign it to System Administrator (Business) — contradiction.
- SYS-UC-001 row: AR user list for Task Management names System Administrator (Business), Sector Manager, and Branch Manager; the English mirror UC001 drops Sector Manager.
- SYS-BR-019: EN BC001 (task reassignment) adds an exception clause ("except for tasks requiring reassignment approval") absent from the Arabic text.
- SYS-BR-020: AR says multiple tasks CAN be reassigned simultaneously; EN says a task can be reassigned multiple times but NOT simultaneously — direct contradiction.
- SYS-BR-024: AR BC006 (Task Management) is a mandatory-field rule; EN BC006 is an activation/deactivation-failure rule — same error code (ERR001), different triggering condition.
- SYS-BR-026: AR and EN describe materially different behavior for case deactivation (suspend linked tasks vs. prevent deactivation/reassignment of a task on a completed case, with warning).
- SYS-BR-027 / SYS-BR-028: AR BC009/BC010 under Task Management duplicate the content of BC006/BC007 verbatim — apparent source duplication, indexed as written.
- SYS-BR-046: Related-entities list email rule — AR says both the contact officer's and the entity's email are shown; EN says the user's own email appears "following the standard format for official communication" — different meaning.
- SYS-BR-053 / SYS-BR-054: Minimum question weight stated as both "not less than 0%" (BC002) and "minimum 5%" (BC003) — unreconciled.
- SYS-BR-061: SLA Management AR BC001 has no rule text, only the repeated section header; the English mirror gives BC001 as "All modifications must be saved successfully in the system."
- SYS-BR-063: SLA Management AR BC003 references error code ERR002; the English mirror references "message MSG00.02" for the same rule — message-code mismatch.
- SYS-BR-075: AR BC005 (Risk Engine) requires the sum of grade weights to equal 100; this rule is entirely absent from the English mirror, whose BC005 slot instead duplicates the Audit Log rule.
- SYS-BR-086: Two of three activity-type risk grades (Medical/Food and Military) share the identical grade value 100 — possible data error, indexed as-is.
- SYS-BR-090: Document states "4 محددات" (4 determinants) for the factory-status risk variable, but only 3 conditions are listed.
