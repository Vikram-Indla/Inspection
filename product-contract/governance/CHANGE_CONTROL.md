# Product Contract Change Control

A frozen contract file may change only through an approved change task.

Required fields:
- Change ID
- Requestor
- Business reason
- Source evidence
- Affected requirements, screens, fields, states, APIs, tests and storyboards
- MVP1/MVP2 impact
- Regression impact
- Decision owner
- Approval
- Effective version

No implementation shortcut is a valid reason to weaken scope.
