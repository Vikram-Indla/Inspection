The chain

Nothing downstream exists until the gate above it is satisfied

These are not conventions. Each gate is a foreign key or a NOT NULL constraint in the schema — the database physically refuses the next step until the row above exists.

Consent

Five decisions I need from you before generating the cohort

01
Riyadh only, or the whole Kingdom?You asked for Riyadh, so the master is 30 Riyadh-region establishments across five industrial cities. The dashboard's region lens and the Operations map are more convincing with several regions. I can add Makkah, Eastern, Madinah and Qassim at the same fidelity — that is roughly 30 more researched rows.
02
The licence number format is unverified.No public source documents it. I matched the shape of a real legacy Ministry export (10-digit numeric). If a trainee cross-checks a number against a live system it will not resolve. Do you want it confirmed with the Ministry or Taadeen first, or is format-plausible enough for training?
03
Do I replace the existing seed, or add alongside it?The real-company rows and the wrong coordinates live in an applied migration. Replacing means a new forward migration that corrects them. Adding alongside leaves SAFCO IV at 88.25 "high risk" visible in the same demo.
04
Which Administration policies may I publish?The inspection-cycle policy, SLA urgency fraction and KPI targets unblock three dashboard measures. Each is a governed value. I will not invent them — I need either the real approved numbers or your explicit sign-off on stated placeholders.
05
Should the generator write to a database in this session?Everything so far is files. Actually loading needs a target, credentials, and a named non-production allowlist. My recommendation is to finish the file layer, have you edit names in the CSVs, and only then wire the loader.
