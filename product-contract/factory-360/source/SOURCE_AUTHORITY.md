# Factory 360 Source Authority

Use this precedence when sources overlap:

1. **Factory_360_Specification_v2.0.docx** — business scope, rules, fields and acceptance.
2. **Inspection_API_documentation.sanitized.json** — documented external API methods, payloads, enums and fields.
3. **FACTORY_360_SPONSOR_DIRECTION.txt** — implementation behaviour, research authority, preservation and closure expectations.
4. **Current repository code and database** — valuable existing functionality must be preserved and extended natively.
5. **SAQEEL_Factory_360_reference.html** — approved layout and interaction direction, never a production data source.
6. **External public research** — clarification only; it cannot override the supplied specification or API contract.

Never commit or use the original unsanitized API collection. Configure provider secrets outside Git.
